第 11 章解决工程决策：什么时候需要训练，什么时候应该先修 Loop、Tool 或 Environment。本章不重复那个问题，而是深入目标函数：示范、偏好和可验证 Reward 如何改变参数。

## 19.1 RL 数学桥梁

MDP 用 $(\mathcal S,\mathcal A,P,R,\gamma)$ 描述状态、动作、转移、Reward 和折扣。对 Agent，权威状态常在 Environment 中，Context 只是部分可观测投影。令 $T$ 表示终止状态下标：状态为 $s_0,\ldots,s_T$，Action 与 Reward 的下标为 $0,\ldots,T-1$，$r_t$ 在 $s_t$ 转移到 $s_{t+1}$ 时产生。对 $t<T$，有限回报为：

$$G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k}$$

策略梯度用采样轨迹估计：

$$\nabla_\theta J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\left[\sum_t\nabla_\theta\log\pi_\theta(a_t|s_t)A_t\right]$$

Actor 产生 Action，Critic 估计 $V(s)$；终止时令 $V(s_T)=0$。TD 残差 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$ 衡量一步后的意外；GAE 汇总剩余 Transition 的残差：

$$A_t^{GAE}=\sum_{l=0}^{T-t-1}(\gamma\lambda)^l\delta_{t+l}$$

在偏差和方差之间折中。$\lambda$ 越小更依赖 Critic，越大更接近长回报。Q-Learning 不直接适配巨大的语言 Action Space，但它帮助理解 Replay、Bootstrapping 和离策略偏差。Reward Shaping 不应把安全 Gate 降级为可抵消的小惩罚。

## 19.2 SFT：学习示范

对示范输出 $y$ 和输入 $x$，SFT 最小化：

$$\mathcal{L}_{\mathrm{SFT}}=-\sum_t\log\pi_\theta(y_t\mid x,y_{<t})$$

Agent SFT 样本应包含任务、Observation、Tool Call、Tool Result、验证和终止，而不只是最终答案。否则模型可能学会“说出好结果”，没有学会“完成过程”。

## 19.3 Reward Model

偏好数据给出 $(x,y_w,y_l)$，Reward Model 可用 Bradley–Terry 概率：

$$P(y_w\succ y_l\mid x)=\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))$$

损失为：

$$\mathcal{L}_{\mathrm{RM}}=-\log\sigma(r_w-r_l)$$

如果标注者只看最终文本，Reward Model 就可能奖励表达流畅而非真实执行。Agent 数据应同时提供轨迹、工具证据与副作用。

## 19.4 PPO

定义新旧策略比率：

$$r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{old}}(a_t\mid s_t)}$$

PPO 的 Clipped Objective 为：

$$\mathcal{L}_{\mathrm{clip}}=\mathbb{E}_t\left[\min\left(r_tA_t,\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)A_t\right)\right]$$

裁剪限制单次更新过大，Critic 估计 Value 以构造 Advantage。RLHF 常加入相对 Reference Policy 的 KL 约束，防止策略为追逐 Reward 过度漂移。

## 19.5 DPO

DPO 将偏好优化写成直接的分类损失：

$$\mathcal{L}_{\mathrm{DPO}}=-\log\sigma\left(\beta\left[\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}\right]\right)$$

它不需要在训练环中同时运行 Critic，但仍然依赖偏好数据质量、Reference Policy 和 $\beta$。偏好数据未覆盖的真实工具失败不会因 DPO 自动消失。

## 19.6 GRPO

对同一问题采样一组输出，用组内 Reward 得到相对 Advantage：

$$A_i=\frac{r_i-\operatorname{mean}(r)}{\operatorname{std}(r)+\epsilon}$$

再使用类 PPO 的比率裁剪和 KL 约束更新。组内归一化降低了对独立 Critic 的依赖，但要求同一问题有足够多样性的候选和可区分的 Reward。

## 19.7 Credit Assignment

终局 Reward 不能自动告诉我们哪一步错了。Agent 轨迹需要区分：

- 模型选错 Tool；
- Tool Schema 不可表达真实操作；
- Environment 返回错误或过期状态；
- Verifier 评错；
- Runtime 在正确决策后超时。

如果把后四种错误全部当作模型 Reward，训练会学习补偿系统缺陷，而不是学习正确策略。

## 19.8 偏好优化变体与选型

| 方法 | 反馈 | 关键几何 | 适合信号 | 主要失败 |
| --- | --- | --- | --- | --- |
| Offline DPO | 固定成对偏好 | 相对 Reference 的 Log-ratio | 高质量离线数据 | 数据分布冻结 |
| Online DPO | 当前 Policy 采样后偏好 | 移动的偏好边界 | 可持续评分新行为 | 采样成本和 Reward 漂移 |
| KTO | 可不配对的好/坏标签 | 相对 KL 基准的效用 | 配对不完整 | 类别不平衡和基准误差 |
| IPO | 成对偏好 | 目标 Margin 的平方距离 | 避免偏好过度拟合 | 目标 Margin 不匹配 |
| ORPO | SFT 示范与偏好 | NLL + Odds-ratio | 单阶段微调 | 两项损失尺度冲突 |
| Best-of-N | 候选分数 | 不改参数，只选样本 | 先验证 Reward | 推理成本按 $N$ 增长 |

先看反馈形式，再看是否能安全在线采样，最后才看训练栈。如果 Best-of-N 都无法用现有 Grader 稳定选出好轨迹，把它用于 RL 风险更大。

## 19.9 Reward 类型与组合

- **Outcome Reward Model (ORM)** 评价终局，信号往往稀疏，也仍可能依赖学习模型或人工判断。
- **Process Reward Model (PRM)** 评价中间状态，信号密集但易奖励表面合理。
- **RLVR** 才把机械可检查性建立在编译器、测试、规则或可执行 Verifier 上。
- **Listwise Reward** 一次比较多个候选，能表达排序，但标注更复杂。

多目标评分要先把未授权副作用、无证据声称和超预算设为不可抵消 Gate，再在通过样本中优化质量、成本和步数。
