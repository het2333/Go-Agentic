## 披露范围

Go Agentic 的课程叙事、章节结构、案例、代码与原创视觉资产由本项目独立创作。本页记录课程实际用于核验事实、解释技术背景、设计练习或检查主题覆盖面的外部资料。列出项目、作者或机构仅表示来源关系，不表示其认可、赞助、隶属或参与维护 Go Agentic。

课程正文以自己的语言解释外部资料。直接引文在正文中使用引号并就近标注来源；第三方名称、商标与链接仍受各自权利和条款约束。

## 软件项目与设计参考

- [Pi](https://pi.dev/docs/latest)：课程核验了其官方站点、Coding Agent README、Session、Compaction 与 Extension 文档，用于讲解终端 Agent Harness、Tool、Session 和扩展边界。Pi 是课程的连续实践参照；本仓库中的离线 Fixture 是独立教学实现，不复刻 Pi SDK。
- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：课程核验了官方仓库、[架构文档](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md)与[安全说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/SAFETY.md)，用于比较插件化 Harness 的组合边界。
- [Hermes Agent](https://github.com/NousResearch/hermes-agent)：课程核验了官方仓库、[产品文档](https://hermes-agent.nousresearch.com/docs/)与[记忆文档](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory)，用于比较持久记忆、定时运行、消息入口、MCP 与隔离子任务等长期运行时服务。
- 参考 PDF：H. Roitman，*《智能体 AI 漫游指南：从基础到系统》*，v1.1.0，本地源文件名 `agentic-ai-guide-zh-v1.1.0.pdf`。课程设计阶段将其作为主题清单，用于检查 Harness、Loop Engineering、Environment、Evaluation、MCP、Skills、A2A 与多智能体等主题是否遗漏；发行版未保留其连续表述、图表、表格或章节结构。

上述三个软件项目与参考 PDF 均为外部参考资料，不是 Go Agentic 的共同作者，也未参与本课程的维护。功能、安装、安全状态与版本行为会变化，采用前应重新核验其一手资料。

## 实际引用的论文与书籍

以下资料在章节的一手资料或证据映射中实际出现；正文中的具体主张应以就近引用为准。

- Agent 与历史基础：Russell 与 Norvig 的 [AIMA agent resources](https://aima.cs.berkeley.edu/)；Newell 与 Simon（1976）的 [*Computer Science as Empirical Inquiry*](https://dl.acm.org/doi/10.1145/360018.360022)；Weizenbaum（1966）的 [*ELIZA*](https://dl.acm.org/doi/10.1145/365153.365168)；Lindsay 等（1980）的 [DENDRAL 项目报告](https://apps.dtic.mil/sti/citations/ADA095109)；Shortliffe 与 Buchanan（1975）的[医学不确定推理模型](https://doi.org/10.1016/0025-5564%2875%2990047-4)；Sutton 与 Barto 的 [*Reinforcement Learning: An Introduction*（第 2 版）](http://incompleteideas.net/book/the-book-2nd.html)；Watkins 与 Dayan（1992）的 [*Q-learning*](https://doi.org/10.1007/BF00992698)；Silver 等（2016）的 [AlphaGo 论文](https://www.nature.com/articles/nature16961)。
- 模型与解码：Kudo 与 Richardson（2018）的 [SentencePiece](https://aclanthology.org/D18-2012/)；Vaswani 等（2017）的 [*Attention Is All You Need*](https://arxiv.org/abs/1706.03762)；Holtzman 等（2019）的 [*The Curious Case of Neural Text Degeneration*](https://arxiv.org/abs/1904.09751)。
- Agent 方法：Yao 等（2022）的 [ReAct](https://arxiv.org/abs/2210.03629)；Wang 等（2023）的 [Plan-and-Solve Prompting](https://arxiv.org/abs/2305.04091)；Shinn 等（2023）的 [Reflexion](https://arxiv.org/abs/2303.11366)；Madaan 等（2023）的 [Self-Refine](https://arxiv.org/abs/2303.17651)；Chen 等（2023）的 [LLMCompiler](https://arxiv.org/abs/2312.04511)。
- 检索、记忆与上下文：Lewis 等（2020）的 [RAG](https://arxiv.org/abs/2005.11401)；Karpukhin 等（2020）的 [DPR](https://arxiv.org/abs/2004.04906)；Robertson 与 Zaragoza（2009）的 [BM25 综述](https://www.staff.city.ac.uk/~sbrp622/papers/foundations_bm25_review.pdf)；Cormack 等（2009）的 [Reciprocal Rank Fusion](https://dl.acm.org/doi/10.1145/1571941.1572114)；Liu 等（2023）的 [*Lost in the Middle*](https://arxiv.org/abs/2307.03172)。
- 学习、评测与测试时计算：Rafailov 等（2023）的 [DPO](https://arxiv.org/abs/2305.18290)；Shao 等（2024）的 [DeepSeekMath](https://arxiv.org/abs/2402.03300)；DeepSeek-AI 等（2025）的 [DeepSeek-R1](https://arxiv.org/abs/2501.12948)；Snell 等（2024）的[测试时计算扩展研究](https://arxiv.org/abs/2408.03314)；Mialon 等（2023）的 [GAIA](https://arxiv.org/abs/2311.12983)；[Berkeley Function-Calling Leaderboard](https://github.com/ShishirPatil/gorilla/tree/main/berkeley-function-call-leaderboard)；Breck 等（2017）的 [ML Test Score](https://research.google/pubs/the-ml-test-score-a-rubric-for-ml-production-readiness-and-technical-debt-reduction/)。
- 训练与推理系统：Hu 等（2021）的 [LoRA](https://arxiv.org/abs/2106.09685)；Dettmers 等（2023）的 [QLoRA](https://arxiv.org/abs/2305.14314)；Rajbhandari 等（2019）的 [ZeRO](https://arxiv.org/abs/1910.02054)；Dao 等（2022）的 [FlashAttention](https://arxiv.org/abs/2205.14135)；Kwon 等（2023）的 [vLLM 与 PagedAttention](https://arxiv.org/abs/2309.06180)。
- 研究工作流：OpenAI（2025）的 [Deep Research System Card](https://cdn.openai.com/deep-research-system-card.pdf)；Shao 等（2024）的 [STORM](https://arxiv.org/abs/2402.14207)；Page 等（2021）的 [PRISMA 2020 statement](https://pmc.ncbi.nlm.nih.gov/articles/PMC8005924/)。
